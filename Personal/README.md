# Personal Files

This directory contains personal MyAnimeList files and customizations used by the repository owner.

These files may include:

- generated anime cover CSS
- generated manga cover CSS
- manual cover overrides
- list-specific CSS
- other personal MyAnimeList customizations

These files are not required to use the generator.

The main generator is located in the repository root:

```text
MyAnimeList-AniList-Better-Cover-Generator.py
```

This directory exists so personal list files can be kept separately from the reusable public generator.
