## Brink Theme

The base theme used here is **Brink** by **Valerio Lyndon**.

Official source:
https://github.com/ValerioLyndon/MAL-Public-List-Designs

A local copy of the Brink CSS is included in this repository only because the base theme together with the custom modifications exceeded MyAnimeList's custom CSS editor limit.

No functional changes were made to the original Brink theme source.  
Only the section/header comments were reformatted to match the rest of the repository.

All custom styling, overrides, and modifications are kept separately in:

`Brink-Theme-Mods.css`

The base theme and custom modifications are intentionally kept separate so the original source remains easy to identify, compare, and update.
